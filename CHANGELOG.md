# Changelog

## 0.9.0-demo.1 — 2026-07-20

### Added

- BG/EN Library, Studio, Saved Projects and Admin interfaces.
- 2D, 3D and Split workspace modes.
- Viewer Manifest v1 data contract.
- Exact-face and recorded-fold rendering pipeline.
- Native 3D, image, dieline and configuration exports.
- Read-only SQLite demonstration adapter.
- Five-product demonstration dataset.
- One-command local demo launcher.
- Unified CI and manually triggered visual QA.
- Project, data, export and security documentation.

### Changed

- Removed temporary branch-specific workflows.
- Stabilized demo timestamps and dataset versioning.
- Hardened database integrity checks and shutdown handling.

### Known limitations

- The canonical production database and real asset bundle are not present.
- Demo products are not manufacturing-approved.
- Production Admin persistence and server export workers require external services.
